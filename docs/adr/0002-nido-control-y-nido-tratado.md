# Nido control y nido tratado para medir la eficacia

Para evaluar la eficacia de la microaspersión se instrumentan dos nidos bajo las mismas condiciones: un nido control que nunca se riega y un nido tratado que recibe microaspersión. Con un solo nido no se puede distinguir si la arena se enfrió por el riego o por un cambio del ambiente (una nube, viento). Por eso el modelo de datos admite N nidos desde el inicio, aunque el prototipo tenga dos.
